# نظام منارات المتحدة للمقايسات والتسعير (v3.1)

تطبيق ويب على Google Apps Script مرتبط بجدول Google Sheets لإعداد المقايسات وعروض الأسعار وحساب تكلفة المشروعات.

## الملفات

| الملف | مكانه في محرر Apps Script |
| --- | --- |
| `Code.gs` | ملف السكربت `Code.gs` |
| `Index.html` | ملف HTML باسم `Index` (الاسم مطلوب كما هو) |

## النشر

1. خذ نسخة احتياطية من ملف الجدول.
2. الصق محتوى الملفين في المحرر مكان القديم.
3. Deploy ← Manage deployments ← Edit ← New version، والدخول «Anyone with Google account».
4. افتح الرابط بحساب مالك الجدول، ومن «الإعدادات ← صلاحيات الدخول» أدخل بريد كل مستخدم مصرح له.
   ما دامت القائمة فارغة يبقى النظام مفتوحاً لكل من يملك الرابط.

## ملاحظات

- `Index.html` لا يعمل منفرداً خارج Apps Script (يعتمد على `google.script.run`).
- جدول الكميات المُصدَّر وتقرير التكلفة يحتويان على التكلفة وهوامش الربح: للاستخدام الداخلي فقط.
