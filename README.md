# نظام منارات المتحدة للمقايسات والتسعير (v3.2)

تطبيق ويب على Google Apps Script مرتبط بجدول Google Sheets لإعداد المقايسات وعروض الأسعار وحساب تكلفة المشروعات.

## الملفات

| الملف | مكانه في محرر Apps Script |
| --- | --- |
| `Code.gs` | ملف السكربت `Code.gs` |
| `Index.html` | ملف HTML باسم `Index` (الاسم مطلوب كما هو) |

## النشر

1. خذ نسخة احتياطية من ملف الجدول.
2. الصق محتوى الملفين في المحرر مكان القديم.
3. Deploy ← Manage deployments ← Edit ← New version، والدخول «Anyone with Google account».
4. افتح الرابط بحساب Google المالك لملف الجدول: ستظهر شاشة «إنشاء حساب المدير» (مرة واحدة فقط).
5. من «الإعدادات ← المستخدمون وصلاحيات الدخول» أضف باقي المستخدمين.

## الدخول والصلاحيات

- الدخول باسم مستخدم وكلمة مرور. كلمات المرور تُحفظ مشفّرة (hash) في خصائص السكربت، لا في الجدول.
- المدير: إدارة المستخدمين وبيانات الشركة والنسب الافتراضية. المستخدم: المشروعات والتسعير والتقارير.
- الجلسة تنتهي بعد 6 ساعات من عدم الاستخدام، والدخول يتوقف 15 دقيقة بعد 5 محاولات خاطئة.
- نسيان كلمة مرور المدير الوحيد: من محرر Apps Script ← إعدادات المشروع ← خصائص النص البرمجي، احذف الخاصية `USER_اسم-المستخدم` ثم افتح الرابط بحساب المالك لإنشاء مدير جديد.

## ملاحظات

- `Index.html` لا يعمل منفرداً خارج Apps Script (يعتمد على `google.script.run`).
- جدول الكميات المُصدَّر وتقرير التكلفة يحتويان على التكلفة وهوامش الربح: للاستخدام الداخلي فقط.
